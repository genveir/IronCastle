This table also serves as the complete list of resource types in the Valley.

| 73-78 | Milk |
| 77-82 | Textiles/Wool |
| 83-90 | Honey |
| 91-96 | Bugs |

| 99 | Rubbish |

Note: the printed table has Milk at 73-78 and Textiles/Wool at 77-82, so 77 and 78 appear in both ranges. Read as Milk 73-76 and Textiles/Wool 77-82, or reroll on an overlap.
