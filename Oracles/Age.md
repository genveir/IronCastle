# Oracle: Age

Roll d100.

| Roll | Age |
|---|---|
| 1 | Baby |
| 2-5 | Child |
| 5-10 | Teenager |
| 11-60 | Young Adult |
| 61-90 | Adult |
| 91-99 | Elder |
| 00 | Ancient |

Note: the printed table has 2-5 Child and 5-10 Teenager, so 5 appears in both ranges. Read as 2-4 Child and 5-10 Teenager.
